# patterns/

存放当前公司的稳定业务规则模式卡。

目录结构由业务域组织，例如：
```
patterns/
├── {业务域-1}/      # 如 private-domain-product/
├── {业务域-2}/      # 如 marketing/
└── universal/      # 跨产品通用规则（见 universal/ 目录）
```

**新入职时**：此目录初始为空，随项目推进通过 `knowledge-archivist` 逐步沉淀。

模式卡格式要求见 `.agent/policies/output-harness.md § 知识模式卡 Harness`。
